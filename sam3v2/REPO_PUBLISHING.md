# Repository Publishing Notes

This workspace was originally based on `facebookresearch/sam3` and has been converted into a standalone project repository for the surgical annotator workflow.

## Intended Git Remote Layout

- `origin`: your private GitHub repository for this project
- `upstream`: optional reference remote pointing to `https://github.com/facebookresearch/sam3.git`

## Required Metadata

- Repository name: `sam3-surgical-annotator`
- Suggested visibility: private
- Suggested default branch: `main`

## Licensing

Keep the existing `LICENSE` file unchanged. This repository contains SAM3-derived materials and should continue distributing the SAM license with the codebase.
